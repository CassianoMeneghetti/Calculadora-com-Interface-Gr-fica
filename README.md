# 🧮 Calculadora Java

Uma calculadora desktop desenvolvida em **Java** utilizando **Java Swing**, com interface gráfica moderna, operações matemáticas básicas e histórico de cálculos.

Este projeto faz parte do desafio pessoal de desenvolver **100 projetos em 100 dias**, com o objetivo de praticar programação, lógica e desenvolvimento de aplicações.

---

## 📸 Preview

> Interface gráfica da calculadora com display, operações matemáticas e histórico de cálculos.

---

## 🚀 Funcionalidades

- ➕ Soma
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão
- 🔢 Números decimais
- % Porcentagem
- ⌫ Apagar último número
- 🧹 Limpar calculadora
- 📜 Histórico de operações
- 🗑️ Limpar histórico
- ⚠️ Tratamento de divisão por zero
- 🖥️ Interface gráfica utilizando Java Swing
